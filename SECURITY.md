# Security policy

This repository is an independent lab prototype (not an F5 product). Please do **not** open public issues for
security problems.

To report a vulnerability, use GitHub's **private vulnerability reporting** for this repository (Security → Report a
vulnerability). If that is unavailable, contact the repository owner privately through their GitHub profile. Include
the affected file or endpoint, the impact, and reproduction steps. Do not include real credentials or customer data.

Supported version: the latest commit on `main` only. Security design notes: [docs/SECURITY.md](docs/SECURITY.md).
